Démarrer

L'appli surveille un dossier d'arrivée (ex. Resilio), reconnaît chaque film ou série avec TMDB et le range dans votre bibliothèque, avec les titres dans votre langue.

  1. Collez votre clé TMDB (Réglages).
  2. Choisissez le dossier d'arrivée et les destinations.
  3. Cliquez Analyser maintenant, puis ouvrez Simulation.
  4. Tout vous convient ? Choisissez le mode.
Au moindre doute, l'appli ne range pas : l'élément va dans À trier.

Simulation et modes

L'onglet Simulation montre tout ce qui se passerait : fichiers à transférer, volume, nouveaux dossiers, renommages, doublons, éléments à trier. Rapport téléchargeable.

  • Simulation seulement (défaut) : rien n'est écrit.
  • Manuel : vous cliquez sur « Ranger ».
  • Automatique : analyse toutes les N minutes et range seul ce qui est sûr. Doublons et doutes ne sont jamais rangés seuls.

Chaque rangement est annulable (Historique).

Clé TMDB

  1. Compte gratuit sur themoviedb.org.
  2. Paramètres → API → Créer → Developer, usage non commercial.
  3. Copiez la Clé API ou le Jeton d'accès (eyJ…), collez-le dans Réglages, puis Tester.

La langue des titres se choisit dans Réglages. Ne partagez jamais votre clé.

Dossiers

  • Arrivée : là où tombent vos téléchargements (avec Docker, le chemin vu du conteneur).
  • Destinations : un dossier par catégorie. Une série existante reçoit la nouvelle saison ; sinon un dossier « Titre (année) » est créé.
  • Copier (conseillé) : l'original reste. Déplacer : après vérification de la copie.
  • Attendre avant de ranger : un élément n'est rangé que si aucun fichier temporaire (.!sync…) n'est présent et si rien de nouveau n'est arrivé depuis N minutes (utile pour une saison dont les épisodes arrivent un par un).
  • Règles : forcent une catégorie (« Pékin Express → télé »).
  • Doublons : ce qui est déjà dans la bibliothèque n'est jamais recopié.

Méthode de copie

Automatique : reflink (instantané, sans place en plus, Btrfs/XFS), sinon lien physique (même volume), sinon copie normale. Avec Docker, utilisez un seul montage pour tout.

Noms des fichiers

Par défaut, les noms d'origine sont gardés (résolution, codec… restent visibles). Vous pouvez aussi cocher ce que vous voulez dans le nom (année, résolution, source, codec vidéo, audio, HDR, langue, groupe), ou choisir les préréglages FileBot / Plex. Un aperçu avant → après est affiché.

Les onglets

  • Détail : chaque élément, ce qui sera fait.
  • À trier : choisissez la bonne fiche, l'appli s'en souvient.
  • Historique : annuler un rangement.
  • Bibliothèque : ce que l'appli a compris de vos dossiers.

Plex, Jellyfin, Home Assistant

Après un rangement, le dossier concerné est rafraîchi (facultatif). Plex : adresse :32400 + jeton (X-Plex-Token). Jellyfin : :8096 + clé (Tableau de bord → Avancé → Clés API). Home Assistant : :8123 + jeton longue durée. Bouton Tester dans Réglages.

Docker

services:
  rangeur:
    image: ghcr.io/VOTRE-COMPTE/kesal-rangeur:latest
    ports: ["3050:3050"]
    user: "1026:100"
    volumes:
      - ./config:/config
      - /volume1/MEDIAS:/media   # un seul montage
    environment:
      KESAL_CONFIG: /config/config.toml

Sécurité et assistant IA

  • KESAL_PASSWORD : mot de passe de l'interface (conseillé hors réseau de confiance).
  • Nom de domaine : à ajouter dans KESAL_ALLOWED_HOSTS.
  • Assistant IA : claude mcp add kesal-rangeur -- kesal-rangeur mcp. Il ne désactive jamais la simulation sans votre accord.

Dépannage

  • Aucune fiche trouvée / mauvais titre : « Corriger la fiche… ».
  • Reste « Transfert en cours » : le transfert n'est pas fini ou un fichier est arrivé il y a moins de N minutes ; réessayez plus tard.
  • Doublon inattendu : la ligne indique le chemin existant.
